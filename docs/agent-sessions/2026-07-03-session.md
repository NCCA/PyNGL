# Agent Session — 2026-07-03 — Math API Consistency

## Goal

Give every math type in `ncca.ngl` (Vec2/3/4, Mat2/3/4, Quaternion, plus
Transform and Vec*Array) one uniform contract: numpy `np.float32` `_data`
storage, immutable-style operations returning new objects, `from_list`/
`from_numpy` classmethods, `copy`/`to_numpy`/`to_list`/`to_tuple`,
`__eq__`/`__hash__`, eval-able reprs, `@` as the linear-algebra product.
Breaking change, no deprecation shims (approved).
