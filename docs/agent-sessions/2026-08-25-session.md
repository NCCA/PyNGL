# 2026-08-25 — Fix Linux CI collection failure (libEGL)

## Goal

The `UV Tests` workflow started failing on `ubuntu-latest` after the Version1.0
merge: 40 of the test modules died during collection with

```
ImportError: libEGL.so.1: cannot open shared object file: No such file or directory
```

Work out why and get the Linux job green again.

## Root cause

Version1.0 moved the OpenGL-coupled modules into a new `ncca.ngl.opengl`
sub-package. `obj.py` now does `from .opengl.base_mesh import BaseMesh, Face`,
and importing a submodule runs the parent package's `__init__.py` first — which
imports `pyside_event_handling_mixin`, which imports `PySide6.QtGui`. So
`import ncca.ngl` now pulls Qt into every test module, the pure-maths ones
included. Before the refactor `obj.py` imported a flat `.base_mesh` and no
package `__init__` ran, so Qt never got loaded.

PySide6's wheels ship the Qt libraries but not the system libraries Qt itself
links against, and the runner has no `libEGL.so.1`. Nothing in the Python code
is broken — the same command passes on macOS.

## Verification

Reproduced in a real `ubuntu:24.04` container (podman) with the repo, `uv sync
--locked --all-extras --dev` and the exact CI pytest invocation — same
`libEGL.so.1` error. Bisected the apt package list down to the six libraries
that are genuinely needed, then re-ran the full CI command in the container:
**579 passed, 198 deselected**, matching the macOS run exactly.

Independent confirmation from the real runner: the Sonar workflow, which
already installs `libegl1`, runs the same imports and completes its coverage
step without trouble.

## Still outstanding

`import ncca.ngl` now drags in PySide6 and PyOpenGL, which contradicts the rule
in `CLAUDE.md` that the top-level package stays API-agnostic. A student on a
headless box cannot `from ncca.ngl import Vec3` without a working Qt/GL stack.
Worth fixing separately — either drop the PySide6 mixin from
`ncca/ngl/opengl/__init__.py`'s eager imports, or move `Obj`'s dependency on
`BaseMesh`/`Texture` behind a lazy import.
