# Agent session — 2026-07-07 — Editable Mat2/Mat3/Mat4 grid widgets

## Goal

Replace the `Mat4ViewWidget` placeholder stub with a real, editable set of
matrix widgets: `Mat2Widget`/`Mat3Widget`/`Mat4Widget`, each an editable
NxN grid with Identity/Zero/Transpose/Inverse reset buttons, plus a method
combo box on Mat3Widget/Mat4Widget (`rotate_x`/`rotate_y`/`rotate_z`/
`scale`/`translate`) that swaps in the right parameter inputs (a degrees
spinbox or an embedded `Vec3Widget`) and recomputes the matrix live.
Brainstormed and designed via the `superpowers:brainstorming` skill (design
approved inline in conversation, not written to a separate spec file at
the user's direction to move straight to implementation), then built
test-first per `superpowers:tdd`/`pytest-best-practices`.

## Files changed

- `src/ncca/ngl/widgets/mat_grid_widget.py` — new private `_MatGridWidget`
  base (not exported): NxN spinbox grid, Identity/Zero/Transpose/Inverse
  buttons, `_status_label` for singular-matrix Inverse errors, `name`/
  `value`-style get/set + Qt `Property`, `set_range`/`set_single_step`,
  and an optional `_add_method_combo()` hook (combo box + `QStackedWidget`
  switching between an angle spinbox and an embedded `Vec3Widget`).
- `src/ncca/ngl/widgets/mat2widget.py` — new `Mat2Widget(_MatGridWidget)`,
  grid + buttons only (Mat2 has no rotate/scale classmethods).
- `src/ncca/ngl/widgets/mat3widget.py` — new `Mat3Widget(_MatGridWidget)`,
  adds the method combo (`rotate_x/y/z`, `scale`).
- `src/ncca/ngl/widgets/mat4widget.py` — replaces the `Mat4ViewWidget`
  stub with `Mat4Widget(_MatGridWidget)`; combo adds `translate`.
- `src/ncca/ngl/widgets/__init__.py` — exports `Mat2Widget`/`Mat3Widget`/
  `Mat4Widget`.
- `tests/test_mat_grid_widgets.py` — new, parametrized over all three
  widget/matrix-class/size combos: construction, grid shape, cell editing
  + `valueChanged`, `set_value`, Identity/Zero/Transpose/Inverse (incl.
  singular-matrix handling), name property, range/step setters.
- `tests/test_mat_method_combo.py` — new, parametrized over Mat3Widget/
  Mat4Widget: combo item list, angle-vs-xyz panel switching, live
  recomputation on parameter change; one Mat4-only `translate` test.
- `tests/test_mat4_widget.py` — deleted (tested the old stub).
- `docs/docs/Widgets.md` — dropped the `Mat4ViewWidget` entry, added
  `Mat2Widget`/`Mat3Widget`/`Mat4Widget` mkdocstrings directives.
- `CLAUDE.md` — widgets architecture bullet updated for the new files.
- `wiki/modules/widgets.md`, `wiki/architecture/overview.md` — content
  updated for the new widgets; `wiki/architecture/api-conventions.md`,
  `wiki/decisions.md`, `wiki/gotchas.md`, `wiki/index.md` — `synced` hash
  bumped only (their CLAUDE.md-tracked content was unaffected by the
  one-line widgets bullet edit).
