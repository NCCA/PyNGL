# Agent session — 2026-07-06

## Goal

Fix `Primitives.create(Prims.LINE_GRID, ...)`: it rendered garbage triangles
instead of a wireframe quad grid.

## Root cause

`_primitive` hard-coded a GL_TRIANGLES VAO with an 8-float
(position, normal, uv) vertex layout for every primitive, but
`PrimData.line_grid` emits position-only 3-float line-endpoint pairs.
The wrong stride spliced positions from unrelated endpoints and the wrong
topology filled them as triangles.

## Files changed

- `src/ncca/ngl/opengl/primitives.py` — `_primitive` now takes
  `draw_mode` and `floats_per_vertex`; `create` maps `Prims.LINE_GRID`
  to `(GL_LINES, 3)` via a layout table (default stays `(GL_TRIANGLES, 8)`).
- `tests/test_primitives.py` — new `test_create_line_grid_lines_layout`
  asserting GL_LINES mode and correct vertex count (written first, TDD);
  removed two dead duplicate `test_create_torus_invalid_sides_rings`
  definitions that were shadowed and called a nonexistent
  `Primitives.create_torus`.
